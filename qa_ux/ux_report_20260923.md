## Что прошло хорошо (не баги)

1. **Компактный сайдбар** — 0 overflow на всех 12 страницах × 2 салона; «Управление» помещается.
2. **Settings = тот же shell** что Bot/App (после фикса layout) — нет «Назад в панель».
3. **Активный пункт** sidebar: Дашборд, Бот, Настройки ЦРМ, Приложение — везда верный.
4. **Статус бота** на `/bot`: зелёный online, heartbeat свежий, токен «настроен».
5. **Меню кнопок** — понятная сетка emoji/название/тип/порядок/toggle/удалить.
6. **Toast** при сохранении приветствия работает.
7. **Корневой URL** → dashboard (не 404).
8. **Сессии мастеров** — таблица с ролями и «Отозвать» понятна; есть «Отозвать все» с confirm.
