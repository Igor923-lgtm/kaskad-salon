# Usability — Telegram-бот · 2026-09-24

**Симптомы (от пользователя):**
1. «Назад» не всегда в самом низу  
2. Иногда **фото внизу, а кнопки сверху** (или без кнопок под фото)

## Корневая причина (фото)

`cb_works_category` (`bot.py`):
1. `edit_message_text("…Отправляю…")` — сообщение **выше** в чате  
2. `reply_media_group(...)` — фото **ниже**; у media_group **нет** `reply_markup`  
3. снова `edit_message_text(..., reply_markup=kb)` — кнопки вешались **на шаг 1**, т.е. **над фото**

В Telegram кнопки всегда у сообщения, к которому attach — поэтому «Назад» оказывался **выше** картинок.

## Исправления

| Где | Что |
|-----|-----|
| `cb_works_category` | «Отправляю…» без кнопок → media_group → **новое** `reply_text` с nav **под** фото |
| `cb_masters` | отправка `photo_file_id` (если есть) с caption, затем **отдельное** сообщение «Выберите действие» + nav |
| `cmd_start` | фото без markup, **меню** текстовым сообщением ниже (порядок корректен) |
| `ensure_back_last()` | helper: дописывает «◀️ Назад», если последняя row не back-like |
| Тесты | `tests/test_bot_keyboard_ux.py` — порядок photo→nav, нет `reply_markup` на media_group |

## Ручная чек-лист-сцена (после деплоя)

1. `/start` → фото → меню **под** фото  
2. 📸 Работы → категория → фото → **кнопки под последней группой**  
3. 👩‍🎨 Мастера → фото/текст → «Выберите действие» **последним**  
4. Любой экран → последняя кнопка **«◀️ Назад»** (или «К категориям»/«Отмена»)
