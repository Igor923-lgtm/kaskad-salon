# GTM — 10 клиентов за 1 месяц (Минск)

**Модель:** только подписка (MRR). Цена = N мастеров × ставка/мес.

## Файлы

| Файл | Назначение |
|------|------------|
| `tracker.csv` | Воронка лидов — вести с дня 1 |
| `onepager.md` | Короткий текст для WhatsApp/TG (копипаст) |
| `scripts.md` | 5 скриптов: первый контакт → подписка |
| `scorecard.md` | Недельные KPI + MRR |
| `week1.md` | Чеклист дней 1–7 |
| `onboarding_pilot.md` | Онбординг пилота ≤ 2 часов |

## Цена (BYN/мес)

- **Solo** — 1 мастер: **79**
- **Команда** — 2–9: **49 × N** (min 245)
- **Салон** — 10+: **39 × N**
- **Сеть** — точки по тарифу, −10% со 2-й

Пилот: **14 дней бесплатно**, без карты → автопродление.

## Воронка

```
Лид → демо 10 мин → пилот 14 дней → подписка (месяц вперёд)
```

## Ежедневный ритм

- **Утро:** 5 персональных сообщений (≤10/день)
- **Вечер:** лог в tracker + follow-up + след. шаг
- **2×/нед:** демо-звонки
- **Пятница:** scorecard vs цель

## Анти-спам

≤10 первых касаний/день · только персональный текст · 1 follow-up через 48ч · 1 звонок · тишина.
