# Онбординг пилота — ≤ 2 часов

Цель: новый тенант принимает тестовую запись через бота и видит её в ЦРМ.

## 0. Перед стартом (5 мин)

- [ ] Согласован пакет на 14 дней (любой, полный функционал)  
- [ ] Имя салона · город · число мастеров · канал (WA/TG)  
- [ ] Дата окончания пилота (старт + 14) → tracker  

## 1. Тенант (15–30 мин)

- [ ] `salons/<id>/.env` (SALON_ID, порт, CRM_SECRET, PUBLIC_BASE_URL, токены бота)  
- [ ] systemd: `{id}-polling` + `{id}-crm` (порядок: polling → crm, если были миграции)  
- [ ] Health: `GET /health` → 200  
- [ ] Логин ЦРМ: 302 → dashboard  

Если деплой на общий хост: см. `deploy_all.sh` / `deploy_salon.py`.

## 2. Данные (30–45 мин)

- [ ] Прайс: CSV или руками (услуги + **duration_minutes**)  
- [ ] Мастера: ФИО, расписание, услуги  
- [ ] Настройки: название, фото/логотип, ссылка на бота  

## 3. Smoke e2e (15 мин)

- [ ] Запись через **Telegram-бота** (тест-номер)  
- [ ] Запись через **/widget**  
- [ ] Слот занят в шахматке ЦРМ  
- [ ] Manage-link: отмена/перенос из ссылки  
- [ ] Напоминание ушло (или лог отправки)  

## 4. Передача клиенту (15 мин)

- [ ] Widget-код админу (iframe/script)  
- [ ] Ссылка на бота салона  
- [ ] Как читать ЦРМ (расписание, клиенты, KPI если ≥5 м.)  
- [ ] Дата окончания пилота + напоминание день 7 и день 13  

## 5. В tracker

- [ ] `pilot_start`, `pilot_end`, `status=pilot`  
- [ ] `next_step` = follow-up day 7  

## Типичные проблемы

| Проблема | Действие |
|----------|----------|
| Бот не отвечает | polling active? токен в .env? |
| Нет слотов | графики мастеров + duration |
| 401 на API | cookie/токен; KPI без auth = 401 ок |
| Порт занят | next free port, обновить env |
